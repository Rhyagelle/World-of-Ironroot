1. **Get Vintage Story.** Buy and download the game from the [official Vintage Story site](https://www.vintagestory.at/). The server runs version {{ site.server.version }}, so make sure yours matches.
2. **Install the required mods.** The [Mods page]({{ '/mods/' | relative_url }}) marks which ones you need. Download each from the mod database and put them in your game's Mods folder before connecting.
3. **Add the server.** In the main menu choose Multiplayer, then Add server, and enter this address: `{{ site.server.address }}`
4. **Ask for a whitelist spot.** {{ site.server.whitelist }}. Tell us your in-game name and we'll add you.
5. **Connect and spawn.** Join from your server list. Your first spawn is at Hollowmere Hall. Check the [map]({{ '/map/' | relative_url }}) to get your bearings.
{: .steps}

## Something not working?

> If the game refuses to connect, the most common cause is a version mismatch or a missing required mod. Check both against this site, then ask for help on Discord.
